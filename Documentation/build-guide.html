01What you're building

One AI agent, reachable from four channels, that qualifies a lead, writes it into HubSpot, and hands it either to a booking link or a nurture sequence — then reminders, then a review or recovery follow-up depending on how the job went. All of the logic lives in four n8n workflows; HubSpot just stores the record.

02Before you start

Accounts to have open in tabs before you begin — each is free to create:

  • A server or host to run n8n on (or n8n Cloud, if you'd rather skip server admin)
  • A HubSpot account (free tier is fine)
  • A Meta developer account at developers.facebook.com, with a Facebook Page and connected Instagram Business account
  • Telegram installed, and access to @BotFather
  • An Anthropic account with billing enabled at console.anthropic.com
  • A Twilio account (free trial credit is enough to test)
  • Admin access to the WordPress site

03Stand up n8n

Since you're already running n8n, skip to confirming these two things — everything else in this guide assumes them:

  1. Your n8n instance is reachable at a public HTTPS URL (webhooks from Telegram/Meta/WhatsApp must be able to reach it — localhost won't work unless tunnelled).
  2. Environment variables are set from config/.env.example — copy it to wherever your n8n host reads env vars from (a mounted .env file for Docker, the host's environment for a VPS, or n8n Cloud's environment variable settings panel) and fill in every value once you have it from the steps below.

If standing up fresh: self-hosted n8n is free software, unlimited workflows/executions — you only pay for the small VPS it runs on (~$5–7/month). n8n Cloud starts at $24/month if you'd rather not manage a server.

04Configure HubSpot

Full field-by-field spec is in Documentation/hubspot-setup.md — do these four things there, in order:

  1. Create a Private App (Settings → Integrations → Private Apps) with the CRM scopes listed in the doc → copy the token into HUBSPOT_TOKEN.
  2. Create the 10 contact properties and 10 deal properties listed in the doc, using the exact internal names given — the workflows reference these names directly.
  3. Rename the default pipeline's stages to match the 7 listed, and copy each stage's internal ID into the matching HUBSPOT_STAGE_* variable in .env.
  4. Create a Meetings link per rep/region (Settings → Objects → Meetings) — free tier has no round-robin, so this is the workaround.
Why polling, not webhooks: a HubSpot Private App can't receive push webhooks on the free plan. Workflows 2–4 check on a schedule (every 15 minutes or daily) instead of reacting instantly — a deliberate, documented tradeoff, not a bug.

05Create the Telegram bot

  1. Open Telegram, message @BotFather, send /newbot, follow the prompts (name + username).
  2. BotFather replies with a token like 123456789:AAxxxxxxxxxxxxxxxxxxx → this is TELEGRAM_BOT_TOKEN.
  3. Create (or pick) a private Telegram group for your team, add the bot to it, and get that group's chat ID (send a message in the group, then check https://api.telegram.org/bot<TOKEN>/getUpdates for the chat.id — it'll be a negative number for a group) → this is TELEGRAM_OPS_CHAT_ID, where escalation alerts land.
  4. No webhook registration step needed yet — that's §11.

06Create the Meta app (Facebook + Instagram)

  1. developers.facebook.com → My Apps → Create App → type "Business".
  2. Add the "Messenger" product, then also add "Instagram" (it reuses the same webhook once your Instagram Business account is connected to the same Facebook Page).
  3. Under Messenger → Settings, generate a Page Access Token for your business Page → META_PAGE_ACCESS_TOKEN.
  4. Choose your own random string for META_VERIFY_TOKEN in .env — you'll enter this same value into Meta's webhook config in §11.
  5. Under App Review, request the pages_messaging and instagram_manage_messages permissions (small businesses can usually self-approve these for their own Page in developer mode without a full review).

07Get an AI model API key

  1. console.anthropic.com → Settings → API Keys → Create Key → ANTHROPIC_API_KEY. This is the default provider (AI_PROVIDER_DEFAULT=anthropic) and the only one required to launch.
  2. Add billing — this is pay-per-token, no monthly minimum. At trade-business lead volumes this runs a few cents per conversation.
  3. Fill in BUSINESS_NAME, SERVICE_POSTCODES, STC_MESSAGE and GOOGLE_REVIEW_LINK in .env — these feed straight into the system prompt (see Documentation/claude-system-prompt.md).
Optional — Gemini and/or Grok: workflow 1's "Build AI Request" node can call any of the three; which one runs is decided per-message by AI_PROVIDER_DEFAULT (all non-website channels) or the website's own "⚙ Integration settings" panel, which sends a preference — never a key — with each lead. To enable a provider, add its key to .env (GOOGLE_AI_API_KEY from aistudio.google.com/apikey, or XAI_API_KEY from console.x.ai) — nothing else changes, the node already knows how to call all three.

08Set up Twilio (SMS fallback)

Used only for leads with no chat channel open (e.g. a website visitor who gave a phone number but never opened Telegram).

  1. twilio.com → Console → copy Account SID and Auth Token → TWILIO_SID / TWILIO_AUTH_TOKEN.
  2. Buy an AU-capable number (or use the trial number for testing) → TWILIO_FROM_NUMBER.
  3. In n8n: Credentials → New → "Basic Auth" → username = Account SID, password = Auth Token → name it exactly Twilio Basic Auth (the imported workflows reference this credential name for the SMS-fallback nodes).

~8c AUD per SMS, billed in USD, no subscription.

09Import the 4 workflows

  1. In n8n: Workflows → Import from File → select each of the 4 files in Workflows/ one at a time.
  2. Open each imported workflow and check every red-underlined node — that usually means an expression referencing a node name that doesn't match exactly (e.g. if you renamed a node while reviewing it). Node names are referenced by exact string in several places ($('Node Name')), so renaming breaks those references.
  3. Confirm your n8n instance has environment variable access enabled for expressions (some hosts disable $env by default for security — if so, either re-enable it for this instance or replace each $env.X reference with an n8n "Variables" lookup instead).
  4. Leave all 4 workflows inactive until §12 testing is done, then activate.
If a node fails to import: delete it and rebuild by hand using the node's parameters block in the JSON file as your field-by-field spec — every value needed is already written out in there (URL, headers, body). This is slower but always works, regardless of n8n version drift.

10Embed the website chat widget

  1. In n8n, open workflow 1, click the "Website Inbound" webhook node, copy its Production URL.
  2. Open Configuration/website-chat-widget.html, replace N8N_WEBHOOK_URL with that URL.
  3. WordPress admin → Appearance → Widgets (or Elementor → add an HTML widget to the footer template) → paste the whole snippet.
  4. This widget is separate from HubSpot's own free chat tool — HubSpot Free's chat doesn't support outbound webhooks, so a small custom widget is what actually lets the AI agent answer on the website. Keep HubSpot's chat tool disabled or human-staffed-only to avoid two bots competing on the same page.
If you're using the main site directly (Website/solterra-landing-au-solarfirst.html) rather than embedding just the widget into a separate WordPress install: it already ships with the chat widget, the quote form, config.js for one-file rebranding, and a separate, password-gated admin.html page — paste the Production URL there and click Test connection, no file editing required. See Documentation/settings-access-guide.md. The steps above are for embedding the standalone widget snippet into a different, existing website instead.

11Wire up webhooks at each provider

Now that n8n has the workflows imported and your webhook URLs exist, point each provider at them.

ProviderWhere to registerURL to enter
TelegramOne-time API call (see below)https://your-n8n/webhook/wf1-telegram
Meta (Messenger + IG)App dashboard → Webhooks → Add Callback URLhttps://your-n8n/webhook/wf1-meta
WhatsApp (optional)App dashboard → WhatsApp → Configurationhttps://your-n8n/webhook/wf1-whatsapp
WebsiteAlready wired via the widget (§10)https://your-n8n/webhook/wf1-website

Telegram doesn't have a dashboard for this — register the webhook with one request:

curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://your-n8n/webhook/wf1-telegram"

For Meta, enter your META_VERIFY_TOKEN value in the same dashboard field — Meta immediately sends a GET request to confirm it, which the "Meta Verify" node in workflow 1 handles.

13Go-live checklist

  • All 4 workflows activated in n8n
  • Real (non-test) Google review link, reschedule link, and business name filled into .env
  • Service postcodes list matches your actual coverage area
  • Meetings links created for every rep/region you operate in
  • Telegram ops group has the right people in it before escalations start firing
  • Twilio number and sender ID sorted (some AU carriers require sender registration for business SMS — check current Twilio AU requirements)
  • HubSpot chat widget turned off or human-only, so it doesn't compete with the custom website widget
  • Ran every test in §12 successfully

14WhatsApp — optional, add later

Not required to launch. When ready:

  1. In the same Meta app from §6, add the "WhatsApp" product.
  2. Get a WhatsApp-enabled phone number ID → WHATSAPP_PHONE_NUMBER_ID, and a permanent access token → WHATSAPP_ACCESS_TOKEN.
  3. Set WHATSAPP_VERIFY_TOKEN to your own random string, register the webhook URL https://your-n8n/webhook/wf1-whatsapp in the WhatsApp Configuration tab with that token.
  4. No workflow changes needed — the WhatsApp webhook, verification, and reply nodes already exist in workflow 1 and the generic-send logic in workflows 2–4; they just start receiving traffic once registered.
  5. Remember: service replies inside the 24h window are free; marketing/utility template sends are billed per message — confirm current Meta AU rates before turning on WhatsApp for the drip sequence specifically.
