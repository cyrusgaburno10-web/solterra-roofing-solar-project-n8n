Launch readiness

    n8n webhook

    Copy this from the Production URL on the "Website Inbound" node in 01-ai-agent-inbound-intake.json, after the workflow is imported and Active in n8n.

    Booking calendar

    From Google Calendar → Create → Appointment schedule → Share → copy the booking page link. Once saved, it shows as "Or pick your own time" on the site's quote card.

    AI model

    This is a preference, not an API key field — deliberately. The website never calls an AI provider directly. This choice is sent along with each lead so n8n knows which model to call; the matching key (GOOGLE_AI_API_KEY or XAI_API_KEY) needs to be added to n8n's own .env to actually activate it.
